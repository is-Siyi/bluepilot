# BluePilot · 多市场投放复盘与诊断

面向出海投放团队的可用型产品 Demo：上传投放数据 CSV，在浏览器本地完成指标计算、异常诊断与复盘报告导出，并与 Coze 大模型工作流分工完成 AI 归因。

**在线体验**：https://is-siyi.github.io/bluepilot/ （免登录，点「载入内置示例数据」即可跑通全流程）

## 解决什么问题

出海投放团队在周度/月度复盘会前，需要从多市场、多渠道数据中回答三个问题：**哪里有问题、可能是什么原因、下一步做什么**。人工汇总耗时长，异常靠肉眼扫，报告措辞靠重写，且数字与结论经常对不上。

## 核心设计：数字归规则，解释归模型

| 环节 | 承担方 | 职责 | 约束 |
|---|---|---|---|
| 数据层 | 本地 Web 应用 | CSV 解析、脏行校验、指标计算、趋势图、多维下钻 | 不做文字归因 |
| 诊断层 | 规则引擎 | 按公开阈值输出 P0/P1/P2 诊断与证据数字 | 不产生规则外结论 |
| 语义层 | Coze 大模型 | 归因解释、复盘表述、待验证假设 | 只允许引用已算出的数字，禁止新增任何数据 |
| 交付层 | 本地 Web 应用 | 七章复盘报告，复制 / 下载 Markdown | 数据全程不出浏览器 |

这个分工回答了 AI 产品的一个关键问题：**计算类的准确性由规则引擎保证，语言类的表达力由大模型提供**，从机制上防止 AI 编造数据。

## 功能清单

- CSV 上传（含引号/BOM 处理），缺列、脏行、除零均有明确反馈，不静默出错
- 8 项指标实时计算：CTR / CVR / CPC / CPA / ROAS 及总量类指标，口径在页面公开
- 环比对比：数据区间后 7 天 vs 前 7 天，不足 14 天自动按前后半段拆分并注明
- 诊断规则 6 条，阈值完全公开可调：高消耗低回报（P0）、市场回报骤降（P0）、转化成本偏高（P1）、点击效率偏低（P1）、转化链路偏弱（P1）、优于均值加预算候选（P2）
- 多维下钻：按市场 / 渠道 / 市场×渠道，表头排序，P0 对象标红
- AI 归因：复制诊断结论 → Coze 工作流归因 → 贴回合并，人工桥接
- 复盘报告生成与下载（Markdown），含口径与限制章节

## 数据格式

一行 = 某市场 × 某渠道 × 某一天，8 个必需列：

```
date, market, channel, spend, impressions, clicks, conversions, revenue
2026-10-01, 美国, Meta, 12000, 480000, 7200, 210, 18500
```

页面提供示例 CSV 下载（224 行，虚构数据，其中包含若干可被规则发现的真实异常）。金额需使用同一币种。

## 技术说明

- 单文件 HTML，无外部依赖，纯浏览器本地计算，数据不上传任何服务器
- 图表为原生 SVG 实时绘制，表格、诊断、报告均由计算结果直接驱动
- 与 Coze 采用人工桥接而非前端直连 API：API 密钥写入前端会泄露，实时对接需后端代理，属于下一阶段的有意取舍

## 本期范围外（明确的取舍）

素材级与人群级归因、多账号权限、数据入库、自动投放执行、实时 API 对接。以上均有对应的进入条件设计，不做无依据扩张。
